미결함 (PENDING)

업무 툴처럼 생긴 어두운 화면에서, 관계자에게 질문하며 단서를 모으고 모순을 찾아 사건을 해결하는 텍스트 추리 게임입니다.

플레이 방법
처음에 난이도를 고릅니다. (편하게 / 보통 / 도전, 언제든 변경 가능)
왼쪽 사건함에서 사건을 고르고, 위쪽 인물 탭에서 대화할 사람을 고릅니다.
아래 질문 카드를 누르면 그 단어에 대해 묻습니다. 대화 속 밑줄 친 단어도 눌러서 바로 물을 수 있고, 직접 입력해도 됩니다.
새로 알게 된 사실은 수첩에 쌓이고, 그 속의 새 단어는 질문 카드로 추가됩니다.
서로 어긋나는 카드 두 장을 골라 **[모순 지적]**을 하고, 그 카드를 당사자에게 제시해 자백을 받아 냅니다.
빈칸을 채워 결재 문장을 완성하면 끝. 점수와 등급(S/A/B/C)이 나옵니다.
막히면 윤 반장에게 "힌트"라고 보내세요.
Esc 두 번 또는 [업무 화면] 버튼: 업무 메모 화면으로 전환
가 버튼: 글자 크기 변경
진행 상황은 브라우저에 저장됩니다.
