업무 툴처럼 생긴 어두운 화면에서, 관계자와 채팅으로 문답하며 사건을 해결하는 텍스트 추리 게임입니다.

플레이 방법
왼쪽 사건함에서 사건을 고릅니다.
위쪽 인물 탭을 누르고 채팅으로 질문합니다. 시각, 장소, 물건 이름을 넣으면 답이 잘 나옵니다.
알게 된 사실은 오른쪽 수첩에 쌓입니다. 진술이 어긋나면 카드의 [제시]로 들이밉니다.
범인, 수단, 결정적 증거를 골라 결재합니다. 기회는 3번입니다.
막히면 윤 반장에게 "힌트"라고 보내세요.
Esc 두 번 또는 [업무 화면] 버튼: 업무 메모 화면으로 전환
가 버튼: 글자 크기 변경
진행 상황은 브라우저에 저장됩니다.
